# QR tools — hosted copy

Static stand-by copy of the Flight OPS Bag QR tools (unit conversion table,
holding speed reference, TEM card, two briefing checklists).

The tools ship inside the iPad application and run from the application bundle
with no network. This deployment exists so the same content can be reached from
an ordinary browser, and so a host application can pick up a newer copy without
waiting for an application release.

No reference documents are published here — they are carried in the
application only.
